# rticx-cortex-m-macro

Proc-macro crate for the [RTICX Cortex-M](https://github.com/rticx-rs/rticx) distribution. Provides the `#[app]` attribute macro.

This is an internal dependency of `rticx-cortex-m`; you likely want [`rticx-cortex-m`](https://crates.io/crates/rticx-cortex-m) instead.
